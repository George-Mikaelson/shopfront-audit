How to read this report

Each area gets a score from 0 to 100: the weighted share of its checks that passed. The overall score combines them (speed 30%, phones 25%, search 20%, accessibility 15%, name/address/phone 10%), leaving out anything we could not measure. “Points” next to a fix is how much the overall score would rise if that problem went away.

Speed is measured with Google Lighthouse on a simulated mid-range phone with a slow 4G connection, so the same page can score a few points differently from one run to the next. Download times assume a typical 5 Mbit/s phone connection.
